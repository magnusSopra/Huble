Drop optional Kjell boss voice clips here:
- kjell_cmon.mp3  (plays when the CMON uppercut actually lands/executes)
- kjell_random.mp3 (random line during the Kjell fight)

Optional per-boss fight music is also resolved from this folder:
- jill_boss.mp3
- sander_boss.mp3
- alf_boss.mp3
- kjell_boss.mp3

Other supported extensions with the same basenames also work. Missing files are handled gracefully with a console warning so fights continue with SFX and the fallback procedural combat stinger.
